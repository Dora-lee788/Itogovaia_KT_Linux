# Bash TUI — Менеджер учебных заметок

## 1. Тема проекта

**Менеджер учебных заметок** — консольное Bash-приложение с текстовым интерфейсом (TUI), предназначенное для добавления, просмотра, поиска, подсчёта и удаления учебных заметок.

Данные сохраняются в текстовом файле внутри каталога `data`.

## 2. Структура проекта

Проект содержит основной Bash-скрипт `app.sh`, файл данных `data/notes.txt`, каталог `reports`, каталог `screenshots` и данный файл `README.md`.

[Скриншот файлов и папок проекта — 02-project-folders.png](screenshots/02-project-folders.png)

## 3. Основной файл приложения

Основной файл проекта — `app.sh`.

В начале скрипта используется shebang `#!/bin/bash`.

Для запуска скрипту было выдано право выполнения с помощью команды `chmod +x app.sh`.

## 4. Запуск приложения

Приложение запускается командой `./app.sh`.

После запуска отображается главное меню с пятью рабочими действиями и пунктом выхода.

[Скриншот главного меню — 03-menu.png](screenshots/03-menu.png)

## 5. Функциональность приложения

### 5.1. Добавление заметки

Пункт 1 позволяет пользователю добавить новую заметку. Введённая информация сохраняется в файле `data/notes.txt`.

### 5.2. Просмотр заметок

Пункт 2 выводит все сохранённые заметки с номерами.

[Скриншот списка заметок — 04-list.png](screenshots/04-list.png)

### 5.3. Поиск заметки

Пункт 3 позволяет выполнить поиск заметки по введённому слову.

Для поиска используется текстовая утилита `grep`.

[Скриншот поиска заметки — 05-search.png](screenshots/05-search.png)

### 5.4. Подсчёт заметок

Пункт 4 показывает количество сохранённых заметок.

Для подсчёта строк используется команда `wc -l`.

[Скриншот подсчёта заметок — 06-count.png](screenshots/06-count.png)

### 5.5. Удаление заметки

Пункт 5 позволяет удалить заметку по её номеру.

Для удаления строки из файла используется команда `sed`.

[Скриншот результата удаления — 07-delete-result.png](screenshots/07-delete-result.png)

## 6. Обработка неправильного пункта меню

В программе предусмотрена обработка неверного выбора пользователя.

Если пользователь вводит пункт, которого нет в меню, программа выводит сообщение об ошибке и возвращает пользователя обратно в главное меню.

[Скриншот обработки неверного пункта — 11-invalid-option.png](screenshots/11-invalid-option.png)

## 7. Хранение данных

Данные приложения хранятся в файле `data/notes.txt`.

Файл изменяется при добавлении и удалении заметок.

[Скриншот итоговой проверки данных — 08-final-check.png](screenshots/08-final-check.png)

## 8. Используемые элементы Bash

В проекте используются shebang `#!/bin/bash`, цикл `while`, конструкция `case`, условия `if`, ввод пользователя через `read`, функции Bash, а также стандартные текстовые утилиты Linux `grep`, `wc`, `sed` и `nl`.

## 9. Проверка проекта

В процессе выполнения проекта были проверены запуск приложения, отображение главного меню, добавление заметок, просмотр списка заметок, поиск заметки, подсчёт количества заметок, удаление заметки, обработка неправильного пункта меню, сохранение данных в `data/notes.txt` и возврат пользователя в главное меню после выполнения действий.

## 10. Итог

В результате создано работоспособное Bash TUI-приложение «Менеджер учебных заметок».

Приложение содержит цикл меню, функции для отдельных действий, условия, пользовательский ввод, работу с файлами и стандартными текстовыми утилитами Linux.

Все основные функции приложения были проверены во время выполнения проекта. Результаты проверки представлены в каталоге `screenshots` и доступны по ссылкам выше.
